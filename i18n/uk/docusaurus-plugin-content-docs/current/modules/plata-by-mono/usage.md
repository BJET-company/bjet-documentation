# Використання модуля

## Оплата з вебсайту Odoo

### Послідовність кроків для оплати

1. Перейдіть на сайт Odoo.
2. Додайте товар у кошик.
3. Перейдіть до оформлення замовлення (Checkout).
4. На кроці вибору способу оплати оберіть **Plata by Mono**.

![Вибір Plata by Mono при оформленні замовлення](/img/plata-by-mono/ua/checkout-select-plata.png)

5. Підтвердіть оформлення — система перенаправить користувача на захищену сторінку monobank.

![Перенаправлення на захищену сторінку monobank](/img/plata-by-mono/ua/redirect-monobank.png)

6. Клієнт проводить оплату карткою на стороні monobank.

![Оплата карткою на стороні monobank](/img/plata-by-mono/ua/monobank-card-payment.png)

### Результат оплати

#### Результат оплати, якщо модуль Бухоблік встановлено (Enterprise)

Якщо модуль **Бухоблік (accountant)** встановлено, після успішної оплати:

1. В Odoo створюється **Замовлення на продаж (SO)** у статусі «Замовлення на продаж».
2. Автоматично створюється **Рахунок**.

![Рахунок створюється автоматично](/img/plata-by-mono/ua/invoice-created.png)

3. Статус оплати рахунку — **В оплаті (In Payment)**.

![Рахунок у статусі «В оплаті»](/img/plata-by-mono/ua/invoice-in-payment.png)

4. Створюється пов'язаний **Платіж** на всю суму оплати зі статусом **В процесі (In Process)**.

![Пов'язаний Платіж у статусі «В процесі»](/img/plata-by-mono/ua/payment-in-process.png)

У полі **Призначення платежу (Memo)** система зберігає унікальний **invoiceId** платежу в системі Plata by Mono. Ця інформація передається у бухгалтерські записи (Journal Items) і використовується для узгодження банківських виписок з платежами Plata by Mono.

5. Також автоматично створюється **Платіжна операція**, перехід до якої доступний з рахунку через **Розумні кнопки**, так само як і перехід до пов'язаного Платежу.

![Платіжна операція, доступна через розумні кнопки](/img/plata-by-mono/ua/payment-transaction-smart-buttons.png)

Для завершення операції необхідно **рознести банківську виписку** та виконати узгодження з цим платежем. Після узгодження статус Рахунку та Платежу зміниться на **Оплачено**.

:::tip Для спрощення звірки
- у **Payment Transaction** в полі **Payment Reference / Provider Reference** зберігається унікальний invoiceId Plata by Mono;
- у пов'язаному **Payment** цей самий invoiceId записується в поле **Memo**.
:::

#### Результат оплати, якщо модуль Бухоблік не встановлено (Community)

Якщо модуль **Бухоблік (accountant)** не встановлено, після успішної оплати:

1. В Odoo створюється **Замовлення на продаж (SO)** у статусі «Замовлення на продаж».
2. Автоматично створюється **Рахунок** у статусі оплати **Оплачено**.
3. Створюється пов'язаний **Платіж** на всю суму оплати зі статусом **Оплачено**.
4. Створюється **Платіжна операція**, перехід до якої доступний з рахунку через розумні кнопки, з інформацією про деталі оплати Plata by Mono.
5. Операція продажу вважається завершеною; окремого процесу рознесення банківської виписки немає.

## Оплата через Посилання платежу (Payment Link)

### Створення посилання на оплату із Замовлення на продаж або Рахунка

Посилання платежу можна сформувати як з Замовлення на продаж, так і з Рахунка.

1. Відкрийте потрібне Замовлення на продаж або Рахунок.
2. Натисніть іконку налаштувань (⚙️) та оберіть дію **Створити посилання платежу**.

![Дія «Створити посилання платежу»](/img/plata-by-mono/ua/create-payment-link-action.png)

3. Система згенерує унікальне посилання на оплату.
4. Скопіюйте посилання, натиснувши **Створити та копіювати посилання платежу** (Generate and Copy Payment Link), та надішліть його клієнту.

![Створити та копіювати посилання платежу](/img/plata-by-mono/ua/generate-copy-payment-link.png)

### Оплата через Посилання платежу

1. Клієнт переходить за отриманим посиланням.

![Клієнт переходить за посиланням на оплату](/img/plata-by-mono/ua/payment-link-customer.png)

2. На сторінці оплати обирає метод **Plata by Mono**.
3. Натискає **Оплатити** — система перенаправляє його на сторінку monobank.
4. Клієнт проводить оплату карткою на стороні monobank.

Наступні кроки в Odoo (створення Рахунка, Платежа, статуси документів) аналогічні до розділу **Оплата з вебсайту Odoo** вище і залежать від того, чи встановлено модуль accountant.

## Повернення коштів (Refund)

Модуль використовує **стандартний механізм відшкодування Odoo** — кошти повертаються на ту саму картку клієнта через API monobank, **без входу в кабінет мерчанта** й без запиту реквізитів.

### Повне повернення

1. Відкрийте **Платіж** (account.payment), здійснений через Plata by Mono.
2. Натисніть кнопку **«Відшкодування» (Refund)**.

![Кнопка «Відшкодування» на формі Платежу](/img/plata-by-mono/ua/refund-button.png)

3. У діалозі сума повернення вже дорівнює повній сумі оплати.

![Діалог відшкодування з повною сумою](/img/plata-by-mono/ua/refund-full-dialog.png)

4. Натисніть **«Відшкодування»** — кошти повертаються на картку клієнта.

### Часткове повернення

1. Відкрийте Платіж і натисніть **«Відшкодування»**.
2. У полі **«Сума повернення»** вкажіть потрібну (меншу) суму, напр. 50 грн із 150 грн.

![Введення суми часткового повернення](/img/plata-by-mono/ua/refund-partial-amount.png)

3. Підтвердіть. «Максимально дозволене відшкодування» зменшиться на повернену суму для наступних повернень.

**Зауваження:**

- Odoo не дозволить ввести суму більшу за «Максимально дозволене відшкодування».
- При **повному** поверненні за Рахунком створюється Credit Note (стандартний flow Odoo).
- Якщо API Mono повертає помилку — система показує причину, а оригінальний Платіж стан не змінює.

## Узгодження банківської виписки (reconciliation)

- Унікальний **invoiceId** Mono зберігається:
  - у Платіжній транзакції — поле **Payment Reference / Provider Reference**;
  - у пов'язаному Платежі — поле **Memo** (значення передається у Journal Items).
- Використовуйте цей invoiceId для зіставлення рядків банківської виписки з платежами.
