# Усунення несправностей

## Типові проблеми та рішення

### Проблема: Plata by Mono не відображається як спосіб оплати на вебсайті

**Можливі причини:**
- Провайдер Plata by Mono перебуває у стані **«Відключено»**.
- Не заповнене поле **Токен API (X-Token)** на вкладці **Облікові дані**.
- Провайдер не опублікований (is_published = True).

**Рішення:**
1. Перейдіть у меню **Бухоблік (Виставлення рахунків) → Налаштування → Провайдери платежу** або **Продажі → Налаштування → Провайдери платежу**.
2. Відкрийте провайдера **Plata by Mono**.
3. На вкладці **Облікові дані** переконайтеся, що поле **Токен API (X-Token)** заповнене.
4. Натисніть **Увімкнути** (Enabled) — для бойового режиму, або **Тестовий режим** (Test Mode), щоб статус провайдера змінився на **Опубліковано**.

### Проблема: Провайдер не налаштований для нової компанії

**Причина:** Налаштування Plata by Mono є **company specific**. Для кожної нової компанії, створеної після інсталяції модуля, провайдера необхідно налаштувати окремо.

**Рішення:**
1. Переключіться на потрібну компанію.
2. Відкрийте провайдера Plata by Mono цієї компанії та налаштуйте його (токен, журнал), як описано в розділі [Налаштування](./configuration.md).

### Проблема: Не вдається виконати повернення або сума відхиляється

**Можливі причини:**
- Введена сума більша за «Максимально дозволене відшкодування» — Odoo цього не дозволить.
- API Mono повернув помилку.

**Рішення:**
- Введіть суму, що не перевищує «Максимально дозволене відшкодування».
- Якщо API Mono повертає помилку — система показує причину, а оригінальний Платіж стан не змінює; перегляньте причину та повторіть спробу.

### Проблема: Рахунок і Платіж лишаються у статусі «В оплаті» / «В процесі» (Enterprise)

**Причина:** Зі встановленим модулем Бухоблік операція завершується лише після узгодження банківської виписки.

**Рішення:**
1. Рознесіть банківську виписку та виконайте узгодження з цим платежем.
2. Для зіставлення рядка виписки з платежем використовуйте унікальний **invoiceId** Plata by Mono — він зберігається у полі **Payment Reference / Provider Reference** Платіжної транзакції та у полі **Memo** пов'язаного Платежу.
3. Після узгодження статус Рахунку та Платежу зміниться на **Оплачено**.
