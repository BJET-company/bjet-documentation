# Налаштування

## Початкові налаштування

Перед використанням:

1. **Загальні налаштування → Веб сайт** — увімкніть прапорець **Автоматичний рахунок** для автоматичного створення рахунків при замовленні з сайту.

![Увімкнення прапорця «Автоматичний рахунок» у налаштуваннях вебсайту](/img/plata-by-mono/ua/website-automatic-invoice.png)

2. **Загальні налаштування → Виставлення рахунків (Бухоблік)** — увімкніть прапорець **Виставити рахунок на онлайн-оплату** для створення посилань на оплату з Замовлень та Рахунків.

![Увімкнення прапорця «Виставити рахунок на онлайн-оплату»](/img/plata-by-mono/ua/invoicing-online-payment.png)

## Налаштування платіжного провайдера Plata by Mono

1. **Автоматичне створення провайдера при встановленні модуля**

Після інсталяції модуля **Платежі Plata by Mono на Odoo вебсайті** в базі для кожної створеної компанії автоматично додається платіжний провайдер у стані **«Відключено»**.

Шлях до провайдера:

- **Бухоблік (Виставлення рахунків) → Налаштування → Провайдери платежу**
- або **Продажі → Налаштування → Провайдери платежу**

Для кожної активної компанії:

- створюється окремий запис провайдера з code = plata;
- початковий стан провайдера — **Відключено**;
- провайдер недоступний на вебсайті та в Payment Link, доки його не налаштовано та не активовано.

![Провайдер Plata by Mono, створений автоматично у стані «Відключено»](/img/plata-by-mono/ua/provider-auto-created-disabled.png)

2. **Робота в мультикомпанійному середовищі**

У базі з кількома компаніями:

- при встановленні модуля провайдер Plata by Mono створюється окремо для кожної компанії;
- налаштування Plata by Mono (токен, журнали тощо) є **company specific** — для кожної компанії унікальні;
- при переключенні активної компанії (Company A → Company B) у списку Payment Providers відображається Plata by Mono саме тієї компанії, яка активна зараз, з її власними налаштуваннями.

3. **Поле API-токена Plata by Mono**

Щоб активувати Plata by Mono, перейдіть у меню **Бухоблік (Виставлення рахунків) → Налаштування → Провайдери платежу** або **Продажі → Налаштування → Провайдери платежу**.

У формі провайдера Plata by Mono на вкладці **Облікові дані (Credentials)** потрібно заповнити поле:

- **Токен API (X-Token)**

![Поле «Токен API» на вкладці «Облікові дані»](/img/plata-by-mono/ua/provider-api-token.png)

Щоб отримати токен, увійдіть до особистого кабінету мерчанта Plata by Mono / monobank і скопіюйте значення **X-Token**.

:::note
Токен зберігається у замаскованому вигляді (як пароль) і не логується.
:::

Вставте значення токена у картку провайдера та натисніть **Увімкнути** (Enabled) — для бойового режиму, або **Тестовий режим** (Test Mode) — для тестування.

Після цього статус провайдера зміниться на **Опубліковано**.

![Статус провайдера змінився на «Опубліковано»](/img/plata-by-mono/ua/provider-published.png)

Перейдіть на вкладку **Налаштування** та знайдіть поле **Способи оплати**. Воно автоматично заповнюється способом оплати **Plata by Mono**. Якщо ж це поле порожнє, відкрийте список усіх способів оплати та активуйте **Plata by Mono**.

![Поле «Способи оплати», заповнене способом Plata by Mono](/img/plata-by-mono/ua/provider-payment-methods.png)

:::info Важливо
- Щоб провайдер відображався на вебсайті, він має бути **опублікований** (is_published = True).
- При **дублюванні** провайдера токен у копії очищується — його потрібно налаштувати заново.
:::

**Налаштування банківського журналу (для Enterprise з Accounting):**

Відкрийте потрібний банківський журнал.

![Відкрийте банківський журнал](/img/plata-by-mono/ua/bank-journal.png)

Перейдіть на вкладку **Вхідні платежі (Incoming Payments)** та вкажіть бухгалтерський рахунок для способу оплати Plata by Mono. Цей рахунок надалі використовуватиметься для формування бухгалтерських проведень за платежами через Plata by Mono.

![Вкажіть рахунок на вкладці «Вхідні платежі»](/img/plata-by-mono/ua/bank-journal-incoming-payments.png)

:::note
Для кожної нової компанії, створеної після інсталяції модуля, платіжного провайдера Plata by Mono необхідно налаштувати окремо.
:::
