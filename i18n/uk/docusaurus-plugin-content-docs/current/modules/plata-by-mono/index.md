# Платежі Plata by Mono на вебсайті

**Технічна назва модуля:** `bjet_plata_by_mono`  
**Платформа:** Odoo 19 (Community та Enterprise)

## Для чого цей модуль?

Модуль **Платежі Plata by Mono на вебсайті** додає в Odoo платіжного провайдера Plata by Mono (monobank) для онлайн-оплат карткою:

- при оформленні замовлень на сайті (eCommerce checkout);
- за посиланнями на оплату (Payment Link) з рахунків (Invoice) та замовлень на продаж (Sales Order);
- через портал клієнта (оплата Рахунку / Замовлення напряму).

Після успішної оплати в Odoo автоматично створюються та зв'язуються між собою:

- Рахунок (Invoice);
- Платіжна транзакція (Payment Transaction);
- Платіж (Payment).

У платіжній транзакції та платіжному документі зберігається унікальний **invoiceId** платежу Plata by Mono для подальшого узгодження банківських виписок.

Додатково модуль підтримує **повне та часткове повернення коштів (Refund)** на картку клієнта прямо з форми Платежу — без входу в кабінет мерчанта.
