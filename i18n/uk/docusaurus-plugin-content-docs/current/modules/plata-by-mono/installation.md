# Встановлення та активація

## Встановлення модуля

1. Перейдіть у меню **Додатки** (Apps).

2. Знайдіть модуль **Платежі Plata by Mono на вебсайті**.

3. Натисніть **Встановити** (Install).

:::info Примітка
Якщо модуль Система оплати [payment] ще не встановлений — він буде встановлений автоматично.
:::

## Наступні кроки

Після встановлення модуля перейдіть до [Налаштування](./configuration.md) для ознайомлення з функціоналом.
