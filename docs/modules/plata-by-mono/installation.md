# Installation and Activation

## Module Installation

1. Go to the **Apps** menu.

2. Find the **Plata by Mono Website Payments** module.

3. Click **Install**.

:::info Note
If the Payment Engine [payment] module is not yet installed, it will be installed automatically.
:::

## Next Steps

After installing the module, proceed to [Configuration](./configuration.md) to learn about the functionality.
